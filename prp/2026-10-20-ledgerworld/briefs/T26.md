## Specification
- `bash scripts/judge-path.sh URL --max-seconds 60`: installs e2e deps if missing, runs Playwright chromium at 1280 px and 390 px, prints the seconds, exits non-zero over the limit or on any failed assertion.
- Assertions per screen: Overview shows cash, the payroll deadline and min projected coverage; Simulation shows the scrubber mid-shock; Decisions shows the surviving plan beside no-action; Execution shows a reconciled receipt (labelled simulated or sandbox).
- After the initial Overview load, the four clicks are Open simulation → Compare policies → View execution → Open receipt. Preserve the backend's prepared demonstration run/execution association. This is anonymous and read-only: zero POSTs, no new financial operation, no invented receipt. Missing prepared data fails honestly. A replay keeps its label and never counts as g3 fresh-branch evidence.
- Time from just before initial navigation through the fourth click's successful receipt assertions, including data loads but excluding dependency/browser installation and browser launch. Report the maximum elapsed over 390/1280/1440 widths and both themes (999 on any failed run); fail above 60 seconds. Check focus, reduced motion, primary 44 px controls, contrast and page overflow from the accessibility fixture. Visit Treasury/Lending read-only outside the timed four-click path for all-screen accessibility; authenticated approval keyboard tests belong only to mocked T19 component tests.

- Never call the real Airwallex API, a real model or the hosted graph memory from a test the merge gate runs; tests use the fake transport, `ScriptedModel` and `FakeGraphMemory`.
- Money is integer minor units with an ISO currency everywhere; a float from a model never reaches a ledger posting or a provider request.
