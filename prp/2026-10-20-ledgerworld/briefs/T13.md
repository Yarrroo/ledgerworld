## Specification
- C3 bound approval: entity, account, amount, plan hash, expiry, mode; any term outside the bound invalidates it. Execution reads the current observed snapshot, never a branch.
- Outbox in the ledger store; each leg has a deterministic `request_id`; state machine pending → submitted → settled | failed | unknown; unknown opens an incident and queries by stored ids before any retry.
- Legs: advance disbursement (lender → borrower), repayment collection, FX conversion, payout to an allowlisted beneficiary (§10 for the operation used by each, including the fallback when connected accounts are not enabled).
- The leg row is written and marked `submitted` (provider id empty) before the connector is called; a restart that finds it so looks it up by `request_id`. A leg runs only after the legs in its `after` list settle; preflight checks every leg (ledger `check_outflow` or the exact held reservation, ownership, beneficiary allowlist, and in sandbox mode the provider wallet) before any is queued.
- A `duplicate_request_id` or `409` on submit is not a failure: look the leg up by `request_id` and adopt the provider object; never resubmit under a new id.
- Reconciliation: provider state → ledger journals; a mismatch is an incident, never an auto-correction. Truth is `GET` by provider id; a webhook is verified (`x-signature` = hex HMAC-SHA256 over `x-timestamp` + raw body, older than 5 minutes → rejected) and only triggers that `GET`; `payout.transfer.paid` is not final.
- Tests (fake transport): no duplicate movement under retries and crashes between steps; no movement from unowned funds; expired or altered approval refused; timeout_after_accept resolves by query; reconciliation closes LF-2's advance.
- Register the test ids in checks/required.json under g1.

## Don't
- Never put a secret in the repo, a log, a fixture, a trace or a test; `.env.example` names variables only.
- Never call the real Airwallex API, a real model or the hosted graph memory from a test the merge gate runs; tests use the fake transport, `ScriptedModel` and `FakeGraphMemory`.
- Money is integer minor units with an ISO currency everywhere; a float from a model never reaches a ledger posting or a provider request.
- A simulation process never holds an Airwallex credential and never imports `app.connectors.airwallex.live`.
- Edit only the files listed under Files you own, plus the one-line wiring your steps name; a wrong contract is fixed in `contracts/` with its example, and the commit says so.
- Upstream files are changed only where the system brief §3 allows it, and every changed upstream file is listed in `ATTRIBUTION.md` in the same commit.
- Never name a person, a team or the system that builds this repo in any repo file; it is a normal open-source project.
- Never push, merge or deploy; the engine publishes your branch.
